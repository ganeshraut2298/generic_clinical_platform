## Differences from the mockup (known, DEC-021 and ADR-013 unless NEW)
UHID shown instead of MRN (OQ-36-8); dates "24 Oct 2026, 9:20 AM IST"; length of stay "Day 1 (today)", "N days", "1 day"; filters also apply to the Table, which has no paging; toolbar, Show-more and action buttons 44 px (mockup 36), flag chips 22 px and non-interactive; actions narrower than the mockup default (OQ-36-4): Transfer for OWNER, NURSE, FRONT_DESK (mockup also DOCTOR), Discharge for OWNER, DOCTOR (mockup hides it from front desk); Deposit, Case paper and Update stage not built; Customize card, My patients, stage chips, Dose overdue and Emergency access flags out; Room cell "—" when rooms are off; the red "Open safety board" banner stays above the toolbar; NEW an inactive member gets 403 on the list; Transfer and Discharge open the existing admission sheet at a start view; the 60-second tab reload replaces the counts-only summary poll on that tab; "+N" reachable only by tooltip or screen reader (R36-2).

## Checked and correct
FRONT_DESK gets no clinical data (`clinical` is `@JsonInclude(NON_NULL)`, absent not null; raw-JSON IT asserts no clinical key; `safety` null; `AdmittedCardRules.both` needs token role AND re-read membership role, four cross-case unit tests); the role gate still tested after the `SafetyService.banner` overload was removed (`AdmissionListCardsTest` plus `AdmittedCardsIT`: no clinical read for FRONT_DESK, role changed between reads, inactive member refused before any read, no membership, role outside the four, IPD Off gives module-off first); no record-access row, audit or event from the list (DEC-021, tested); fixed number of set queries (placement left join to room, one `liveEscalations` read shared by banner/counts/flags, latest vitals lateral `limit 1`, one patient batch; 100- and 300-patient tests); one `asOf` DB clock read for every minute count and Vitals due; clinical rules in `EscalationClock`, `VitalsDue`, `MedicineSafetyCheck.allergyStatus`, none in the browser; contract matches the Java shapes; frontend standalone/OnPush, card is an `article` named "<name>, bed <code>", action names "<Action> for <name>", in-memory view state only, F-1 fix (`openById` passes `autoFocus:false` only for 'move'; test ipd.page.spec.ts:960), F-3 fix (`.iptbl` position relative), `pollList` skips the summary poll on the Admitted tab, stale-data line `role="status"`.

## Done well
FRONT_DESK exclusion enforced twice (serialiser and role check) and tested at raw-JSON level; abilities come from the server; the sheet starts at a start view without new endpoints; about 90 new frontend specs.
