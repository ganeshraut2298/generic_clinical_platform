## solution-architect, ADR-018 Revision 3 (11 Nov 2026): done (documents only)
Tech lead check: `docs/api/admin.yaml` parses (14 paths); `validate docs` fails only on ADM-2.md. Files: ADR-018 (Revision 3), `docs/api/admin.yaml` (still 0.5.0; no operation renamed).
- **M1: the tech lead's suggested design (count inside `begin`, same transaction) does NOT fix it:** any rollback after the compare (audit insert, lock write, failed commit, dropped connection) would also undo the count, so the wrong-PIN path could still answer 500 while the correct PIN answers 200. **Chosen design, new D4 "count first, judge after":** two short transactions plus a 30-second lease in the state row (only one try in flight). (1) Claim (T1): `begin(try_id)` adds 1 to the count; the 5th try also sets the 60-minute lock and clears the ticket; hands the lease to this try and COMMITS; Java compares only after that commit returns. (2) The BCrypt compare runs outside any transaction (no row lock or connection held).
