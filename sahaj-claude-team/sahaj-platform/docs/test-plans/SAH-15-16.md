# Test plan: SAH-15 Today dashboard and SAH-16 Revenue report

Branch: feature/SAH-13-appointments-workspace. Mockup screens: Today (`vToday`), Revenue (`vRevenue`).
Real-database integration tests (profile `test`, `sahaj_test`, MockMvc, nothing mocked):
`backend/src/test/java/com/sahaj/platform/it/TodayDashboardIT.java`, `RevenueIT.java`, helper `BackdateSupport.java`.
SAH-14 follow-up lists: `FollowUpListsIT` (unchanged, re-run).

Back-dating: the clock cannot move, so `BackdateSupport` runs committed SQL as `sahaj_app` with the tenant bound.
`opd.visit` (created_at, stage) and `opd.follow_up` (due_date) are UPDATEd. `billing.payment` is append-only (trigger),
so old payments are INSERTed with an explicit `recorded_at`. Dates use noon IST so day boundaries are unambiguous.
